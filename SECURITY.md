# Security Policy

## Supported version

Only the version currently deployed from `master` receives security updates.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
[admin@passi.cloud](mailto:admin@passi.cloud) with reproduction steps, affected
routes or components, and the expected impact. Do not include real banking data,
access tokens, certificates, or private keys.

Reports will be acknowledged as soon as practical. Confirmed issues will be fixed
and disclosed according to their severity; no monetary bug bounty is offered.
